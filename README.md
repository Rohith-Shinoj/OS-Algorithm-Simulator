#  OS Algorithm Simulator

A web-based simulator for various Operating System algorithms, including Process Scheduling, Page Replacement, and Banker's Algorithm. This interactive platform is designed to help students and enthusiasts understand core OS concepts through visual demonstrations.

Website is live at [https://rohith-shinoj.github.io/OS-Algorithm-Simulator/](https://rohith-shinoj.github.io/OS-Algorithm-Simulator/)

---

## 📌 Features

- Process Scheduling Algorithms (First Come First Serve (FCFS), Shortest Job First (SJF), Round Robin, etc)
- Banker's Algorithm and Deadlock Avoidance
- Secondary Storage/Disk Scheduling Algorithms (FCFS, SCAN, C-SCAN, etc)
- Process Synchronization through interactive simulations of 3 classic problems:
  1. Dining Philosopher
  2. Reader-Writer
  3. Producer-Consumer 
- Multiprogramming Techniques - Fixed Tasks (MFT) and Variable Tasks (MVT)
- Page Management Algorithms - FIFO, Least Recently Used (LRU) and Optimal
- File Management Techniques in Operating Systems:
    1. Single level Directory
    2. Two level Directory
    3. Tree Directory

## Getting Started Locally

You can run the simulator locally for testing or development purposes.

### Step 1: Clone the Repository

```bash
git clone https://github.com/Rohith-Shinoj/OS-Algorithm-Simulator.git
cd OS-Algorithm-Simulator
```

### Step 2: Run using Python HTTP Server (Recommended)

```bash
python3 -m http.server <port>
```

The web content may also be accessed by opening the index.html file (in the root directory) in a browser.
